# Mobile Product Page Optimization

Applied to the 19 PDF-based product pages only.

- Mobile hero order changed to: product category/title, image slider, Request a Quote + Add RFQ buttons, then short description and PDF description text.
- Desktop hero layout remains side-by-side with text/actions on the left and product slider on the right.
- Key Features, Typical Applications and repeated bullet-card sections now use a compact 2-column mobile grid to reduce page length.
- GCC country cards now use a compact 2-column mobile grid and 4-column desktop grid.
- Request a Quote and Add RFQ buttons use a 2-column mobile row and retain the same RFQ functionality.
- PDF product content, GCC SEO copy, FAQs, thumbnails, product archive order, meta title and meta description were left unchanged.
